A - 百万富翁

大概就是每次可以询问一对 \((i,j)\) 位置，要求出序列中的最大值是谁。
首先一个直观的想法就是每次两两分组打擂台，然后递归所有胜者，但是我们发现这样不能够通过，因为这个题目要求询问轮数只能是 \(8\)，而我们的这个做法需要询问 log 轮。同时我们可以注意到，我们可以询问的次数是大于 n 的，所以自然可以猜想，我们可以调整最后的几次操作，看看能不能满足要求。
具体的，我们可以设 \(f_{i,j}\) 表示 \(i\) 个人，经过 \(j\) 次轮操作之后只剩下 一个人的代价最小是多少，转移就是 \(f_{i,j} = f_{p, j - 1} + cost(i, p)\)，其中 \(cost(i,p)\) 指的是把 \(i\) 个人经过一轮操作剩下\(p\) 个人的最小代价，显然，因为代价类似于二次函数，所以每一组分成的人数大概一样的时候代价最小，换句话说，我们将所有人划分成 \(p\) 组，每一组之间两两比较，最后每两组之间最多相差一。这个可能还是跑不出来，但是其实这就是个打表题，而且我们可以猜测，前面几次都是两两分组。

B - 元旦激光炮

联合多分！
这是一道交互题。

给你三个排好序的数组，让你在有限次数询问中找到第 \(k\) 小值。
经典做法：先把 \(a,b,c\) 都 resize 到 \(k\) 我们设置 \(l = \lfloor \frac{n}{3} \rfloor\)，接下来询问 \(a[l],b[l],c[l]\) 这三个位置，我们找到这三个值中的最小值，并删除这个最小值所在的数组的前 \(l\) 个元素，容易证明这 \(l\) 个元素不可能是可行的第 \(k\) 小值，所以直接递归到 \(k-l\) 的子问题就行，\(k < 3\) 的时候特殊处理一下。
特别的，对于只有两个数组的时候，我们有更加优秀的做法，联合二分，我们可以每次把两个数组都删去一半，让迭代更快。

C - 生产计划 (Day 2)

好题，首先我们定义 \(L, R\)。

  • 如果 \(\forall a_i=l_i\)，求出的答案为 \(L\)。
  • 如果 \(\forall a_i=r_i\)，求出的答案为 \(R\)。

先所有位置都取 \(l_i\) 我们考虑给某一个位置增加 \(1\)，最大独立集要么增加 \(1\) ，要么不变，袋券独立集的答案 \(ans \in [L, R]\)。我们仔细思考每个位置从 \(l_i \to r_i\) 的过程，发现一定是一开始它不在独立集里面，然后随着它增大，它进入了独立集，此后每次 \(+1\) 答案都 \(+1\)，我们可以用动态 \(dp\)，维护这个东西，但是太麻烦，我们其实可以使用换根 dp，按照 dfs 序遍历即可。

D - 末日魔法少女计划

确实好题。

首先 \(k = 2\) 的时候是猫树 \(k = logn\) 的时候是线段树。
这题的思路其实还是 dp 构造，我们沿用猫树的构造，每次确定中间的链接点，然后仍然是把剩余区间平均分，但是这里需要注意，两端的点不需要向单边连边，所以可以设置的稍微长一点。
具体 dp 不是很重要，就不写了。

F - 编程测试

首先我们看到这个题目可以建网络流，但是我们肯定不能暴力去跑，注意到这个网络流类似二分图匹配，于是我们考虑霍尔定理，然后二分答案 \(x\) 再用霍尔定理 check，容易发现，只 check 每个区间即可，不需要 check 每一个子集。
然后观察到 \(l=1\) 的特殊性质，我们可以直接用 李超线段树+二分 处理出所有前缀答案。但是 \(l\) 不是 1 怎么办呢，我认为这种问题要么扫描线，要么分治，我们考虑后者，这样我们每次处理跨过当前 mid 的区间，都在左右端点都在左边的，我们只需要用 李超线段树判断是否有交点就行（这个地方好像题解继续用二分，导致复杂度变成 \(O(nlog^3n)\)）。然后跨段的，我们发现左右端点的决策是独立的，所以我们分开用两个可持久化李超线段树，然后二分答案，找到两侧的最值 check 即可。

G - 穿越

没有见过这样的题目，好题。
我竟然没有想出来单组 \(A,B\) 怎么做。
对于单组 \(A,B\)，我们可以用 segment tree beats，我们就只有几个操作

  • \([Y1[i], Y2[i]]\) 区间加。
  • 查询全局 min
  • 全局 (min _+ B) 对全局进行 check min

但是，我们没办法快速回答多组询问，于是我们考虑答案在什么时候取道，经过思考发现，这个答案一定在 横轴为 A 的个数，纵轴为 B 的个数的一个凸包上，于是我们考虑线段树莓哥节点是一个凸包，然后我们在凸包意义下做这个操作就好。
但是注意一下，这个复杂度不是 \(O(n^2 \log n)\) 的，因为 \(A,B\) 个数的值域都是 \([1,n]\) 所以有一个结论，凸包的节点只有 \(n^{\frac{2}{3}}\) 个。
于是复杂度为 \(O(n^{\frac{5}{3}}\log n)\)。

J - Souvenirs

支配对经典题目，其实 \((a\_i - a\_j)\_{\min}\) 和 \((a\_i + a\_j)\_{\min}\) 都是可以求出来的，不同的是，前者的支配对个数为 \(O(n \log n)\) 但是后者的支配对个数为 \(O(n)\)。

K - rpmtdq

我们知道序列上 \(a_i + a_j\) 的支配对个数是 \(O(n)\) 的，但是现在在树上，我们考虑树上的序列哪里来，容易想到是点分治，这样我们每次把当前连通块内的点到分治中心到距离当作 \(a_i\)，对这个序列统计支配对就好，最后回答询问的时候全部离线，然后扫描线即可。
注：在分治中心 \(rt\) 同一个子树内的点对的距离不是 \(a_i + a_j\) ，但是他的答案我们算大了所以不会影响最终的答案。

M - 骰子 / Kostki

推式子题目，设 \(f_i\) 表示刚好跳到 \(i\)，\(g_i\) 表示跳过了 \(i\)，落在 \([i+1,i+k-1]\) 的概率。推式子不想讲。

update: 2026.11.25:
来补充一下这个题目的做法

现在看来这个题目其实并不困难。

首先肯定是拆开贡献。
我们先只考虑一个人的操作序列，记 \(f_i\) 为这个人恰好经过了位置 \(i\) 的概率。
可以简单递推得到：

\[f_0=1,\qquad f_i=\frac1k\sum_{j=\max(0,i-k)}^{i-1}f_j \quad(1\le i<m).\]

使用前缀和优化可以 \(O(n)\) 得到整个 \(f\)。

接下来考虑如何正确计算所有人一起走的贡献。

先来讲一个比较精妙的做法。

我们考虑当前在最前面的有 \(c\) 个人，位置为 \(s\)，这一次行动直接走到 \(\geq m\) 的位置的概率为 \(p_i\)，那么可以知道

  1. 如果只有一个人，有 \(p_i\) 的概率直接结束，总投掷次数为 \(1\)，在这一阶段结束的概率为 \(p_i\)。
  2. 如果有两个人，第一个人的情况已经分析过了，在第二个人的时候有 \(p_i\) 的概率结束，两个人汇总总投掷次数为 \(1+(1-p_i)\)，到第二步之前已经结束的概率为 \(p_i+p_i\times(1-p_i)\)
  3. 如果有三个人，省略，分析差不多。

所以不难发现，总投掷次数和在 \(s\) 位置结束的概率之间的关系总是 \(p_i\) 倍。

所以只需要想办法计算出 \(S_i=\Pr(L\geq i)\)，由各人的骰子序列独立，

\[\Pr(\text{最后一次行动从 }i\text{分出发}) =S_i^n-S_{i+1}^n.\]

\(S_i\) 递推式，

\[S_{i+1}=S_i-f_ip_i.\]

还有一个之前的推二项式定理的做法，其实就是没有发现总投掷次数和在 \(s\) 位置结束的概率之间的关系总是 \(p_i\) 倍。

这里我懒得写了，基本一致，最后代码写出来也是基本一样的，就是推到过程更复杂了。

gemini:

这道题（P15985 [PA 2026] 骰子 / Kostki）可以通过将玩家过程独立化并按当前全局最小得分 \(s\) 拆分期望来在 \(O(m + \min(m, k) \log n)\) 时间内解决。

核心思路

1. 独立序列与全局最小得分

设想每名玩家 \(i \in \{1, \dots, n\}\) 都拥有一条互相独立的无限掷骰子序列，对应的累计得分序列为 \(0 = S_{i,0} < S_{i,1} < S_{i,2} < \dots\)。

由于骰子点数至少为 \(1\)，且每次总是当前得分最低的玩家行动：只要还有任何玩家得分小于 \(s\)，得分已经 \(\ge s\) 的玩家就绝对不会再次行动。因此，对于任意得分阈值 \(s \in \{0, 1, \dots, m-1\}\)，游戏能够在未结束的情况下推进到“所有玩家得分均 \(\ge s\)”，当且仅当每一名玩家在独立序列中首次达到 \(\ge s\) 时的得分都严格小于 \(m\)。

2. 状态概率递推

首先，设 \(p_s\) 表示单个玩家从 \(0\) 分出发，在独立掷骰过程中恰好踩到得分 \(s\) 的概率：

\[p_0 = 1, \quad p_s = \frac{1}{k} \sum_{d=1}^{\min(k, s)} p_{s-d} \quad (1 \le s < m)\]

利用滑动窗口维护前 \(k\) 项之和，可以在 \(O(m)\) 时间内求出所有 \(p_s\)。

对于固定的 \(s \in [0, m-1]\)，考虑单个玩家首次到达 \(\ge s\) 时的得分 \(Y(s)\)，可分为三种互斥情况：

  • \(Y(s) = s\)（恰好停在 \(s\)）：概率为 \(a_s = p_s\)。
  • \(s < Y(s) < m\)（从 \(< s\) 跨过 \(s\)，但仍未获胜）：记概率为 \(b_s\)。
  • \(Y(s) \ge m\)（在到达 \(s\) 之前就已经从 \(< s\) 直接跳到 \(\ge m\) 结束游戏）：概率为 \(1 - a_s - b_s\)。

设 \(S_s = a_s + b_s\) 表示单个玩家首次到达 \(\ge s\) 时尚未触发 \(\ge m\) 的概率。显然 \(S_0 = 1\)。从 \(s\) 推进到 \(s+1\) 时，唯一新增的“在 \(< s+1\) 处直接获胜”的情况，就是玩家先恰好踩到 \(s\)（概率 \(p_s\)），再从 \(s\) 一掷达到 \(\ge m\)。记从得分 \(s\) 一掷获胜的概率为：

\[w_s = \frac{\max(0, s + k - m + 1)}{k}\]

于是有递推式：

\[S_{s+1} = S_s - p_s \cdot w_s\]

（特别地，当 \(s \le m - k\) 时，\(w_0 = \dots = w_{s-1} = 0\)，因此恒有 \(S_s = 1\)。）

3. 统计在最小得分 \(s\) 处的期望投掷次数

由于每次投掷都在某个唯一的当前最小得分 \(s \in [0, m-1]\) 处发生，由期望的线性性，总投掷次数期望等于 \(\sum_{s=0}^{m-1} E_s\)，其中 \(E_s\) 为在最小得分 \(s\) 处发生的投掷次数期望。

若所有玩家均满足 \(Y_i(s) < m\)，且其中恰好有 \(r\) 名玩家停在 \(s\)、\(n - r\) 名玩家在 \((s, m-1]\)，这 \(r\) 名玩家会按随机顺序依次从 \(s\) 投掷，只要前面没有人投出 \(\ge m\)（每次继续的概率为 \(q_s = 1 - w_s\)），下一名玩家就会继续投掷：

  • 第 \(1\) 名玩家投掷的概率为 \(1\)；
  • 第 \(2\) 名玩家投掷的概率为 \(q_s\)；
  • ……
  • 第 \(j\) 名玩家投掷的概率为 \(q_s^{j-1}\)。

对所有 \(r\) 求和，得到：

\[E_s = \sum_{r=1}^{n} \binom{n}{r} a_s^r b_s^{n-r} \sum_{j=1}^{r} q_s^{j-1}\]

分两种情况化简：

  1. 当 \(w_s = 0\)（即 \(s < m - k\)）时：此时 \(q_s = 1\) 且 \(S_s = a_s + b_s = 1\)，内层求和为 \(r\)，由二项分布期望公式得：
\[E_s = n \cdot a_s \cdot (a_s + b_s)^{n-1} = n \cdot p_s\]
  1. 当 \(w_s > 0\)（即 \(s \ge m - k\)）时：利用等比数列求和 \(\sum_{j=1}^r q_s^{j-1} = \frac{1 - q_s^r}{w_s}\) 与二项式定理得：
\[E_s = \frac{(a_s + b_s)^n - (q_s a_s + b_s)^n}{w_s} = \frac{S_s^n - (S_s - w_s p_s)^n}{w_s}\]

复杂度分析

  • 时间复杂度：\(O(m + \min(m, k) \log n)\)。前 \(m - k\) 项只需 \(O(1)\) 计算，后 \(\min(m, k)\) 项每次使用快速幂即可。
  • 空间复杂度：\(O(m)\)，用于存储 \(p\) 数组。

化成独立随机游走

每名玩家的得分序列 \(0=s_0<s_1<s_2<\cdots\) 与其他人无关。”得分最低的人行动”等价于：所有行动按”行动前的得分”从小到大依次进行，同分的玩家按随机顺序行动。

定义几个量

令 \(u_s\) 表示一名玩家的得分序列经过 \(s\) 的概率：

\[u_0=1,\qquad u_s=\frac1k\sum_{d=1}^{k}u_{s-d}\quad(\text{下标小于 }0\text{ 的项取 }0)\]

用前缀和可以 \(O(m)\) 求出。再定义：

\[\mathrm{cnt}_s=\max(0,\;k-m+s+1),\qquad c_s=\frac{\mathrm{cnt}_s}{k}\]

这里 \(\mathrm{cnt}_s\) 是从 \(s\) 出发一步能到达 \(\ge m\) 的点数，\(c_s\) 是一步结束的概率。

\[x_s=u_s\,c_s,\qquad q_s=\sum_{p<s}x_p\]

\(x_s\) 是恰好从 \(s\) 出发跨过终点的概率，\(q_s\) 是在 \(s\) 之前就已经跨过终点的概率。

期望的线性性

总行动次数等于 \(n\) 乘以”玩家 1 在位置 \(s\) 的行动是否发生”的概率之和。玩家 1 在 \(s\) 处的行动发生，需要同时满足三个条件：

  1. 玩家 1 经过 \(s\)；
  2. 其他人没有在 \(s\) 之前就结束；
  3. 在位置 \(s\) 的随机顺序里，没有”在 \(s\) 处跨过终点的人”排在玩家 1 前面。

设其他 \(n-1\) 人中恰有 \(B\) 个在 \(s\) 处跨过终点。无论玩家 1 自己是否在 \(s\) 处跨过终点，他排在这 \(B\) 个人之前的概率都是 \(\frac1{B+1}\)。令 \(r=1-q_s-x_s=1-q_{s+1}\)，则玩家 1 在 \(s\) 处行动的概率为：

\[P(s)=u_s\sum_{B=0}^{n-1}\binom{n-1}{B}\,x_s^{B}\,r^{\,n-1-B}\cdot\frac1{B+1}\]

化简

利用 \(\binom{n-1}{B}\frac1{B+1}=\frac1n\binom{n}{B+1}\) 和二项式定理：

\[\sum_{j=1}^{n}\binom nj x_s^{j}r^{\,n-j}=(x_s+r)^n-r^n=(1-q_s)^n-(1-q_{s+1})^n\]

所以

\[P(s)=\frac{u_s}{n\,x_s}\Big[(1-q_s)^n-(1-q_{s+1})^n\Big]=\frac{(1-q_s)^n-(1-q_{s+1})^n}{n\,c_s}\]

最终公式

分两段计算：

  • \(s<m-k\) 时 \(c_s=0\)，不可能有人提前结束，每个人经过 \(s\) 就一定行动，贡献为 \(n\,u_s\)。
  • \(s\ge m-k\) 时用上面化简后的式子，再乘以 \(n\)。

合起来：

\[\boxed{\;E=n\sum_{s=0}^{m-k-1}u_s+\sum_{s=\max(0,\,m-k)}^{m-1}\frac{k}{\mathrm{cnt}_s}\Big[(1-q_s)^n-(1-q_{s+1})^n\Big]\;}\]

第一项仅当 \(m>k\) 时存在，否则为 \(0\)。另外 \(q_m=1\)，所以最后一项里 \((1-q_m)^n=0\)。

复杂度

  • 因为 \(\mathrm{cnt}_s\le k<10^9+7\)，所以逆元都存在，可以线性预处理 \(1..k\) 的逆元。
  • 每个 \(s\) 做一次快速幂，总复杂度 \(O(m+k\log n)\)。
  • \(n=k=m=10^6\) 时实测约 \(0.1\) 秒。
